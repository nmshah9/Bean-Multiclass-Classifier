# Dry Bean Type Classification — End-to-End ML Project

Automates dry bean type classification (7 classes) from 16 camera-measured
physical features, replacing a manual, error-prone classification process.

## Project Structure

```
beans_project/
├── data/
│   └── Dry_Bean_Dataset.xlsx          # raw dataset (13,611 rows)
├── notebooks/
│   └── Beans_Multiclass_Classification.ipynb   # full walkthrough, all steps explained + plots
├── src/                                # reusable, tested modules (imported by both notebook and app)
│   ├── config.py                       # paths, constants, random seed
│   ├── data_loader.py                  # Step 1: load + validate
│   ├── eda.py                          # Step 2: exploratory analysis + plots
│   ├── preprocessing.py                # Steps 3-4: cleaning, outliers, scaling, encoding, split
│   ├── imbalance.py                    # Step 6: SMOTE / oversampling / undersampling / class weights
│   ├── modeling.py                     # Step 5: candidate classifiers + cross-validation
│   ├── evaluation.py                   # Step 7: metrics, confusion matrix, overfitting check
│   └── tuning.py                       # Step 8: GridSearchCV / RandomizedSearchCV
├── models/                             # generated by train_pipeline.py — required by app.py
│   ├── best_model.joblib
│   ├── scaler.joblib
│   ├── label_encoder.joblib
│   ├── feature_names.json
│   ├── model_comparison.csv
│   └── metadata.json
├── train_pipeline.py                   # runs every step end-to-end, saves all model artifacts
├── app.py                              # Streamlit prediction app
├── requirements.txt
└── README.md
```

## How to Run

### 1. Install dependencies
```bash
pip install -r requirements.txt
```

### 2. Train the model (only needed once — artifacts are already included, but re-run any time to retrain)
```bash
python train_pipeline.py
```
This runs all 9 modelling steps (load → EDA-ready cleaning → preprocessing →
multi-model comparison with CV → SMOTE imbalance handling → hyperparameter
tuning → final evaluation) and saves everything into `models/`.
Takes roughly 5–10 minutes on a standard laptop CPU.

### 3. Launch the Streamlit app
```bash
streamlit run app.py
```
Opens in your browser at `http://localhost:8501`. Three tabs:
- **Manual Prediction** — enter one bean's measurements, get an instant class + confidence chart
- **Batch Prediction (CSV)** — upload a CSV of many beans, download predictions
- **About This Model** — shows which model won, its accuracy/F1, and hyperparameters

### 4. Explore the notebook
Open `notebooks/Beans_Multiclass_Classification.ipynb` for the fully-explained,
step-by-step walkthrough (with every plot and the reasoning behind each
decision) that `train_pipeline.py` runs as a script.

## Current Results

| Metric | Value |
|---|---|
| Best model | SVM (RBF kernel, tuned) |

| Weighted F1 | 92.66% |

See `models/model_comparison.csv` for the full comparison across all 11 model
variants tried (8 baseline classifiers + top-3 with SMOTE + the final tuned model).

## Deployment Notes

- All package versions in `requirements.txt` are pinned to match the versions
  used to train the saved model (scikit-learn 1.8.0), avoiding the
  "unpickling with a different sklearn version" warnings/errors common on
  Streamlit Community Cloud.
- `best_model.joblib` is ~520 KB — well under GitHub's file-size limits.
- `requirements.txt` is named exactly that (Streamlit Cloud requires this
  exact filename to auto-detect dependencies).
- Folder structure is kept shallow to avoid Windows path-length issues.
